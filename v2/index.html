Mots-clés de classement

Un mot-clé trouvé dans l'intitulé d'une réserve lui attribue le code BPU ; si l'intitulé ne donne rien, on cherche dans l'observation (badge « via observation » à vérifier). Majuscules et accents ignorés ; si plusieurs correspondent, le plus bas dans la liste l'emporte (mettez les mots généraux en haut, les plus précis en bas).
